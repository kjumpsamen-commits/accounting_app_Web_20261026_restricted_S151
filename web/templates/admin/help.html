2. 交接時怎麼改（建議做法：不用改程式）
  1. 新負責人把 data.db 放到自己的 Google Drive（或在桌面程式「設定 → 資料庫位置」指到 Google Drive 同步資料夾）。
  2. 在 Google Drive 對該檔案按「共用」→ 一般存取權改成「知道連結的任何人」（檢視者），複製連結。
    連結格式：https://drive.google.com/file/d/這一段就是 File ID/view
  3. 到 Render 控制台 → 這個網站的服務 → Environment → 新增或修改 GDRIVE_FILE_ID，貼上新的 File ID → 儲存。Render 會自動重新部署（約數分鐘）。
  4. 重新部署後到「管理設定」按「立即同步」，確認首頁資料是新帳本的資料，並回到本頁確認「來源」顯示為「Render 環境變數」。
環境變數的優先順序最高，會蓋過程式內附的值，而且不會因為重新啟動而消失。
3. 不建議：在管理設定頁直接改 File ID
管理設定頁的「儲存設定」會寫入伺服器上的 {{ info.yaml_path }}。 Render 免費方案的檔案系統是暫時的：服務重新部署、重新啟動或休眠（15 分鐘沒有人使用就會休眠）時，這個修改就會消失，恢復成程式內附的值。 如果 Render 有設定環境變數，重新啟動後也會以環境變數為準。只適合「暫時測試一下新的 File ID」。

5. File ID 什麼時候會變
  • 不會變：同一個檔案被覆寫、或 Google Drive 電腦版同步更新同一個檔案。
  • 會變：刪掉後重新上傳、上傳成另一個檔案、或用桌面程式「設定 → 資料庫位置 → 變更」搬到另一個資料夾（會產生新檔案）。這時就要照第 2 節更新 File ID。
  • 完整版與受限版如果是兩個不同的 Render 服務，兩個都要更新。
6. 安全提醒
檔案設定成「知道連結的任何人」，所以 File ID 等於整個帳本的鑰匙：拿到 File ID 的人可以直接下載 data.db。
  • 程式的 Git 儲存庫請保持私人（目前程式中內附了 File ID）。
  • 要把程式交給別人或公開前，先刪除第 4 節列出的 File ID，改用 Render 環境變數。
  • 交接後，舊負責人的 Google Drive 檔案請取消「知道連結的任何人」分享。
