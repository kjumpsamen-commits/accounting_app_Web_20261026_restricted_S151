# 01 系統總覽

> 版本：20261027 V3.12

## 1. 這是什麼

羽球隊後援會的記帳軟體，分成三個部分，共用**同一個資料庫檔案 data.db**：

| 部分 | 給誰 | 功能 | 程式 |
|---|---|---|---|
| **桌面版**（Windows） | 管帳的人 | 記帳、月費、特殊收費、統計、匯出、備份、結轉。**唯一可以修改資料的地方** | `accounting_app_V3_*.zip`（PySide6） |
| **網頁完整版** | 管帳的人 | 唯讀查詢全部記帳、統計、月費、特殊收費 | `accounting_app_v996_V2_Web_special_charge_v6_*.zip`（FastAPI） |
| **網頁簡易版** | 成員、家長 | 唯讀，只有「繳費狀況」「特殊收費」 | `..._restricted_*.zip`（同一套程式，整站受限） |

## 2. 資料流

```
桌面版（修改資料，每次直接寫入 data.db）
   │  關閉程式時記錄「最後存檔時間」、自動備份到 backups/
   ▼
data.db（放在 Google Drive 電腦版同步的資料夾）
   │  Google Drive 自動上傳
   ▼
Google Drive 上的 data.db（同一個檔案，File ID 不變）
   │  兩個網站各自定期下載（預設每 30 分鐘；啟動時也下載；管理頁可立即同步）
   ▼
網頁完整版（Render）       網頁簡易版（Render）
```

- 網頁不會寫回資料庫；兩個網站各自下載一份。
- 結轉是在同一個 data.db 上進行，Google Drive 上仍是同一個檔案（S13 Q1）。
- 網頁的 File ID 與更換方式見 [07 建置與部署](07_建置與部署.md) 與網頁管理設定的「資料來源說明」。

## 3. 資料夾（桌面版電腦上）

| 位置 | 內容 |
|---|---|
| `data.db` | 資料庫（預設在使用者資料夾的 `.accounting_app`；可在設定頁變更位置） |
| `backups/`（data.db 旁） | 自動備份：關閉時（有修改才備份）、升年級前、結轉前、還原前；上限 10 份 |
| `封存帳本/`（data.db 旁） | 結轉時封存的舊帳本 `帳本_第一筆日期-交接日.db` 與同名 `.xlsx` |
| `data.db.bak_*`（data.db 旁） | 程式更新、資料庫升級前的一次性備份；變更位置覆蓋前的備份 |
| `config.json`（`.accounting_app`） | 資料庫位置設定（只有自訂位置時才有） |
